# Illustrations

Original line-art illustrations for Reversia — thin dark-green linework
with soft sage-green watercolour washes, in the fresh theme's palette.

They are original in-house artwork made for the app, so there is no
licence issue (unlike the food photos in `../foods/`, some of which are
blog-sourced and still need swapping before shipping).

## Files

| File | Used for |
| --- | --- |
| `welcome-hero.png` | Final onboarding slide ("Ready when you are") |
| `empty-meals.png` | "No meals logged yet" empty state (Repeat Meal) |
| `empty-readings.png` | "Log your first glucose reading" empty state (Home chart) |
| `milestone-plant.png` | Reversal Plan milestones, once a milestone is reached |
| `guide-sprout.png` | Reversia Guide empty-chat companion, under the headline |

## Format

All five are tall portraits (1120 × 2240, 1:2) with the subject in the
lower half and generous empty wash at the top — by design, so the screens
have breathing room. Display them with `resizeMode="contain"` and give
them room (roughly 170–260pt tall depending on the spot). Do not crop
them; the empty space is part of the drawing.

Their backgrounds are a very pale sage wash (corners around
`#F3F1EB`–`#F8F8F3`), close to the fresh theme background `#E9F1E2`, so
they sit directly on sage screens without a card. The one exception is
the onboarding slide, which sits on a green gradient — there the hero
lives in a white rounded card.
